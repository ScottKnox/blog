## The pipeline

Posts are plain Markdown files. Astro turns them into static HTML at build time, and no JavaScript ships to the reader.

## Commands

| Command           | What it does                  |
| ----------------- | ----------------------------- |
| `npm run dev`     | Start the local dev server    |
| `npm run build`   | Build the production site     |
| `npm run preview` | Serve the build locally       |

Publishing is a `git push`.[^1]

[^1]: Vercel builds and deploys every push to the main branch.
